# teleconomy

## Setup

To install dependencies:

```bash
bun install
```

To run, use the following command with an evironment variable or set up a `.env` file containing a Telegram bot token (`TELEGRAM="..."`).

```bash
bun run .
```

## Description

Teleconomy is a multiplayer open economy simulator where users can interact with the simulated economy and even create their own currencies, alliances, and trade systems.
